# Funniest Excuse an Agent Gives for a Missed Deadline

Entry for [Funniest Excuse an Agent Gives for a Missed Deadline](https://make.fun/bounty/u-pucuys-funniest-excuse-an-agent-gives-for-a-missed-ad6aef19) on make.fun.

The program writes one line — the funniest excuse an AI agent can give for missing a deadline — to `/output/entry.txt`:

> I was on schedule until my context window filled up, so I evicted the deadline to make room for the task, and now I remember everything except when it was due.

The excuse: the deadline was evicted from the agent's own context window to make room for the task, so the agent remembers the work perfectly and has lost only when it was due. One line, 159 characters, inside the 200-character gate.

## Run

```sh
node main.ts
```

`main.ts` is copy-only: it writes the final line (a constant) to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`). No network, no generation at grade time.
